工作原理

简单三步，开始生成 AI 视频

1

安装依赖

安装 Python 依赖和 Playwright 浏览器

pip install -r requirements.txt
playwright install chromium
2

配置 Claude Desktop

在 Claude Desktop 配置文件中添加 MCP 服务器

"mcpServers": {
  "pixelle-video-server": {
    "command": "python",
    "args": ["path/to/server.py"]
  }
}
3

开始生成

在 Claude 中直接调用视频生成工具

"生成视频，文本：如果防止上头，分镜数5，音量调到5倍"

快速安装

几分钟内即可开始使用

作为独立脚本使用

python generate_video.py -t "你的文本内容" -s 5 -v 1.0
-t, --text 要输入的文本内容（必需）
-s, --slider 分镜滑块值 (5-30)，默认 5
-v, --volume TTS音量值 (0.1-5.0)，默认 1.0
--headless 无头模式运行浏览器

MCP 工具

generate_video_tool

自动生成视频，支持自定义参数

• text: 要输入的文本内容
• slider_value: 分镜滑块值 (5-30)

常见问题

快速解答您的疑问

生成的视频文件保存在哪里？
生成的视频文件会保存到 .cache/videos/ 目录，文件名格式为：{时间戳}_{文本前20字}_{原始文件名}.mp4，例如：20250415_143022_这是一段测试文本_video_0.mp4
如何在 Claude Desktop 中配置？
在 Claude Desktop 的配置文件中添加 MCP 服务器配置：
macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
Windows: %APPDATA%\Claude\claude_desktop_config.json
支持哪些参数配置？
支持多种参数配置：文本内容、分镜滑块值（5-30）、TTS音量值（0.1-5.0）、Streamlit 应用 URL、无头模式开关、超时时间等，满足不同场景需求。
如何使用无头模式？
在命令行中添加 --headless 参数即可启用无头模式，浏览器将在后台运行，不会显示界面。
